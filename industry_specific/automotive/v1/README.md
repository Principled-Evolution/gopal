# Automotive Vehicle Safety Policies

Source:
- **ISO 26262** — Road vehicles: Functional safety — https://www.iso.org/standard/68383.html
- **ISO/PAS 21448 (SOTIF)** — Safety of the Intended Functionality — https://www.iso.org/standard/70939.html
- **UNECE Regulations on Automated Driving** (WP.29) — https://unece.org/transport/vehicle-regulations/wp29/wp29-regulations-under-1958-agreement

This directory contains `vehicle_safety/vehicle_safety.rego`, which checks hazard analysis and risk assessment (HARA), ASIL determination, SOTIF analysis, and operational design domain (ODD) definition for AI systems used in vehicles.
